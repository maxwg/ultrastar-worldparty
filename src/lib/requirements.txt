Historical dependency and build notes
======================================

This file preserves older WorldParty dependency notes. It is not the current
setup checklist for this checkout.

Current source build
--------------------

For current source-build prerequisites and commands, see
../../CONTRIBUTING.md. The package checks are defined in ../../configure.ac.
That configure script requires Free Pascal 3.0 or newer, a C compiler, and
pkg-config. It checks SDL2, SDL2_image, FreeType, SQLite, and Lua 5.1 or newer
as required packages. It requires pkg-config metadata for libavformat and
libavutil, probes libavcodec conditionally, and checks detected FFmpeg versions
against its compatibility table. FFmpeg support is enabled only when all three
libav packages are available.

The repository's ../../autogen.sh runs autoreconf. Install the Autotools needed
by autoreconf when regenerating the configure script.

Historical Linux notes (not current)
------------------------------------

The following package instructions refer to Ubuntu 7.04 and Fedora 8. They
are kept for historical context and do not describe the current build
requirements.

Ubuntu 7.04:

    sudo apt-get install libavcodec-dev libavformat-dev libsqlite3-dev libsdl-ttf2.0-dev libsdl-image1.2-dev

To generate the configure files with autogen.sh, the old notes also requested:

    sudo apt-get install automake autoconf

Fedora 8 (contributed by kdub):

    yum install ffmpeg-devel SDL_ttf-devel SDL_image-devel sqlite-devel

Historical Mac OS X notes (not current)
---------------------------------------

These notes referred to Apple's Developer Tools, Xcode, and Fink. They listed
Free Pascal 2.2.2 or later and the following Fink packages:

    fink install pkgconfig libavcodec-dev libavformat-dev libavutil-dev libswscale-dev
    fink install SDL SDL-image libpng3 sqlite3-dev

The FPC minimum above predates the current configure.ac requirement of 3.0.0.
